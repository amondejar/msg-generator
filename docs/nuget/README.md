# Stratum

Stratum generates .NET 10 microservices with your team's conventions and keeps them up to date: a CLI (`stratum`),
a visual editor (`stratum studio`) and an MCP server for AI assistants.

This package is one of its building blocks (the packages are named StratumKit.*; the code inside keeps the
Stratum namespaces):

| Package | What it brings |
| --- | --- |
| `StratumKit.Cli` | The `stratum` tool: `dotnet tool install -g StratumKit.Cli` |
| `StratumKit.ServiceDefaults` | Health checks, ProblemDetails, correlation id, idempotency keys, validated options |
| `StratumKit.ServiceDefaults.OpenTelemetry` / `.Resilience` / `.Authentication` | OpenTelemetry, resilient HttpClients and service discovery, JWT authentication |
| `StratumKit.Ddd` | Aggregates, domain events, domain exceptions, commands, queries and handler contracts |
| `StratumKit.Messaging` (+ `.EntityFrameworkCore`, `.Kafka`, `.AzureServiceBus`) | Integration events: outbox, idempotent consumers, retries, dead-letter, traces |

Services generated by Stratum reference these packages; `stratum upgrade` moves them to a new version.

```bash
dotnet tool install -g StratumKit.Cli
stratum new Orders
stratum add entity Order --path orders --props "Number:string, Total:decimal"
stratum studio
```
